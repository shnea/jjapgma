# 메인 레이아웃과 캐러셀

공식 템플릿 **워크스페이스 메인**(`main`)은 일반 컴포넌트 조합이다. 새 페이지의 시작 템플릿 또는 왼쪽 템플릿 탭에서 사용할 수 있다. 빈 페이지에서도 아래 요소를 직접 넣어 동일한 동작을 구성한다. 별도 서비스·환경변수·마이그레이션은 없다. 외부 파일은 기존 file-service 지침을 유지하며 추가 UI는 자체 공통 Registry/렌더러에서 제공한다.

## 메인 화면 구성

- 상단 컨테이너: 문자 로고·서비스명, 메뉴 검색, 아바타. 로고는 이미지로 교체하거나 삭제할 수 있다.
- 아래 가로 컨테이너: 사이드 패널과 남은 공간을 채우는 본문. 본문에는 경로 표시만 두어 자유롭게 화면을 구성한다.
- 기본 테마는 흰 헤더/메뉴, 밝은 본문, 보라색 선택 표시다. 모바일에서는 헤더의 로고 앞 메뉴 버튼으로 같은 메뉴가 화면을 덮는 서랍으로 열린다. 버튼은 일반 button과 overlayAction으로 구성한다.
- 루트 최소 높이는 100dvh이며 헤더 아래 본문이 남은 높이를 채운다. 실제 화면/HTML 내보내기는 브라우저의 동적 화면 높이, 편집기는 여백과 확대율을 제외한 캔버스 가시 높이를 사용한다. 내용이 길면 스크롤된다. 최상위 요소의 ‘화면 높이 이상 채우기’ 설정으로 조절한다.
- Storybook의 입력창·캐러셀 예시는 동작 검증용이며 공식 main 템플릿의 본문에 강제로 포함하지 않는다.

## 사이드 패널 / 독립 서랍

| 설정 | 동작 |
| --- | --- |
| panelSide | left/right. 오른쪽은 형제 본문 오른쪽에 배치 |
| panelMode | fixed는 항상 펼침, collapsible은 경계 버튼으로 접기 |
| collapseMode | rail은 좁은 너비로 아이콘 유지, hidden은 완전히 숨김. 다시 열기 버튼 유지 |
| collapsedWidth | 접힌 너비 40–120px |
| defaultCollapsed | 데스크톱 최초 접힘 상태. 미리보기 재진입 시 초기화 |
| mobileDrawer | 모바일에서 같은 내용을 본문 위로 겹쳐 표시. 기본 true |
| mobileTrigger | auto는 패널 기본 버튼, external은 헤더 등에 배치한 일반 버튼의 overlayAction으로 열기. main 템플릿은 external |
| drawerScope | parent는 부모의 보이는 영역, page는 페이지의 보이는 영역 |
| collapseVisibility | 자식 요소를 항상/펼칠 때만/접힐 때만 표시. 패널 밖에서는 영향 없음 |

패널 안에는 메뉴 외에도 컨테이너·검색·로고·입력 등을 자유롭게 넣을 수 있다. 일반 버튼/아이콘의 창 액션 대상에 sidePanel 또는 drawer를 지정해 open/close/toggle한다. 패널 너비는 공통 스타일, 접기 가능 여부는 내용 속성이며 스크롤 상단 고정과는 독립이다.

접기 버튼은 패널과 같은 배경의 둥근 탭으로 경계에 이어진다. 완전히 접어도 탭은 남는다. 긴 메뉴는 패널 안에서 스크롤되며 본문을 밀어 늘리지 않는다. 아이콘만 남긴 상태의 하위 메뉴는 바깥 팝업으로 열고 Escape·바깥 클릭으로 닫는다.

drawer는 데스크톱에서도 쓸 수 있는 독립 서랍이다. 기본적으로 닫혀 있고 액션으로 연다. 배경을 덮고 입력을 차단하며 Esc·닫기 버튼·선택적인 배경 클릭으로 닫는다. 키보드 포커스를 안에 유지하고 닫을 때 트리거로 복귀한다. 메뉴 선택 시 모바일 패널을 닫는다. 편집 모드에서는 닫힌 서랍도 표시해 자식을 배치할 수 있다.

빌더에서는 페이지/부모의 화면에 보이는 부분으로 범위를 제한한다. 편집기 전체를 덮지 않는다. 서랍 안의 긴 내용은 별도로 스크롤되며 드래그로 창을 이동하지 않는다. 기존 모달·다이얼로그의 동작은 유지한다.

## 메뉴 / 검색

navbar의 기존 줄바꿈 items는 계속 지원한다. 속성의 **아이콘·하위 메뉴 편집 사용**으로 menuItems 구조로 전환할 수 있다. 항목의 이름·실제 아이콘·이동 주소·배지·비활성화·모바일 숨김·순서·상위 메뉴를 편집한다. 그룹 제목·구분선과 **최대 3단계(대/중/소)** 메뉴를 지원하며 UI·서버·MCP 명세에서 4단계를 거절한다. 선택 항목의 상위 경로를 표시/펼치며 주소가 있는 부모는 이름으로 이동하고 화살표로 펼친다. 이동 주소는 사이트 내 경로·앵커·http/https만 허용한다. 실제 업무 페이지나 라우터를 자동 생성하지 않는다.

searchBox에서 **검색할 메뉴**를 선택하면 입력 즉시 해당 navbar의 이름/하위 메뉴를 검색한다. 검색 결과가 있는 하위 메뉴는 펼쳐 표시하며 지우기 버튼을 제공한다. 연결이 없으면 입력 UI만 동작한다. 업무 DB 검색은 구현 범위가 아니다. 좌·중·우 정렬은 검색 요소가 차지한 영역 기준이며, 헤더 전체 정중앙이 필요하면 동일 너비의 좌/중/우 컨테이너를 구성한다. 모바일 입력 유지 또는 아이콘 확장을 선택할 수 있다.

검색 대상 ID는 그룹 복제·템플릿 재사용 및 MCP get_template의 안정적인 ID 변환에도 같이 바뀐다. 원본 메뉴를 잘못 검색하지 않는다. 펼침/선택/검색어 등 런타임 상태는 설계 문서의 저장 값과 분리한다.

## 캐러셀

carousel의 직계 자식 하나가 슬라이드 하나다. 이미지·카드·컨테이너 등 어떤 요소도 넣을 수 있다. 여러 요소로 한 장을 구성하려면 컨테이너/카드 안에 넣는다. 편집과 미리보기 모두 같은 크기에 한 장만 표시한다. 오른쪽 슬라이드 목록에서 썸네일·이미지 URL·추가·순서·삭제를 관리하고, 카드 내부는 레이어에서 선택하면 해당 장으로 전환한다. 편집 중 선택은 화면 명세에 저장하지 않는다.

- carouselVariant: controls(하단 버튼), arrows(이미지 좌우 화살표), regions(좌우 영역 클릭). 영역 클릭은 내부 입력/버튼/링크를 제외하며 방향키도 지원한다.
- carouselSizing: ratio/fixed. carouselRatio는 16/9·4/3·1/1·21/9, carouselHeight는 80–1600px. 공통 스타일 높이를 명시하면 그 외곽 높이 안에 맞춘다.
- carouselFit: cover(영역 채우기)/contain(전체 이미지). 직계 이미지 슬라이드에 적용하며 이미지 비율/로딩에 따라 캐러셀 크기가 변하지 않는다.

- 이전/다음, 특정 페이지 점, 현재 장수, 마지막→처음 반복 여부를 각각 설정한다.
- 자동 재생 기본 OFF, 간격 2–30초. 일시정지/재생 버튼과 hover·focus 시 멈춤. 사용자 수동 전환 후 일시정지.
- 시스템의 움직임 줄이기 설정에서는 자동 전환하지 않는다.
- 좌우 스와이프와 키보드로 접근 가능한 조작 버튼. 입력·링크 등 내부 조작에서는 스와이프를 시작하지 않는다.
- 보이지 않는 슬라이드는 포커스/접근성 대상에서 제외하되 내부 입력 상태를 보존한다.

## 공통 배치 / AI / 내보내기

### 테마와 독립 스크롤

메인 템플릿의 로고/헤더/메뉴/본문과 검색·캐러셀 조작은 페이지 테마 색상에 연결된다. style의 색상 값은 `theme:primary`, `theme:onPrimary`, `theme:background`, `theme:surface`, `theme:text`, `theme:muted`, `theme:border`를 사용할 수 있다. Inspector의 색상 연결에서 역할 또는 직접 지정을 선택한다. 직접 고른 HEX/transparent는 테마 변경에도 유지한다. 저장된 기존 템플릿 트리의 자동 색상 변환은 하지 않는다(현재 사용자는 새 구성을 기준으로 진행하도록 요청).

서랍과 접힌 메뉴의 팝업도 원래 페이지의 테마를 사용한다. 패널 경계 버튼의 바깥 테두리는 패널과 같은 색/굵기를 사용하고 붙는 면은 선을 없앤다. 모바일 서랍은 캔버스 확대율을 반영한 실제 보이는 영역 안에 들어오며 긴 메뉴는 안에서 스크롤한다.

`overflowX`/`overflowY`는 가로/세로 각각 visible(영역 밖 표시), auto(자동), scroll(항상), hidden(숨김)이다. 기기별로 설정할 수 있다. 좌측 메뉴와 우측 본문은 각 요소의 높이/최대 높이와 스크롤을 별도로 설정한다. CSS 규칙상 한 축을 스크롤로 설정하면 다른 축 visible은 auto로 계산된다. 세로 스크롤에는 제한된 높이가 필요하다. 기존 `overflow` 값은 두 축의 공통 기본값으로 계속 읽는다.

grow는 부모의 남은 공간 채우기, shrink=false는 축소 방지, sticky는 스크롤 영역 상단 고정이다. 최소/최대 너비·높이도 속성에서 설정할 수 있다. 기기별 스타일 저장을 지원한다. CSS flex 문자열을 명세에 직접 넣지 않는다.

Registry·서버 Zod 명세·팔레트·Inspector·MCP가 같은 컴포넌트와 속성을 사용한다. get_design_context에 sidePanel/drawer/searchBox/carousel을 지정하면 명세를 받을 수 있고 일반 add/update 작업으로 만들 수 있다. main은 기존 공식 템플릿 경로로 조회/제안한다. 별도 템플릿 전용 스크립트를 만들지 않는다.

HTML ZIP은 같은 NodeRenderer와 런타임을 사용하여 패널·메뉴 검색·서랍·캐러셀을 오프라인에서도 실행한다. 실제 인증·업무 검색·메뉴 이동 대상 서비스는 사용자가 연결해야 한다.
