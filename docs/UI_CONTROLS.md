# 편집기 컨트롤 동작

2026-09-16 사용자 정정 사항을 적용한 기준입니다.

메인 템플릿·사이드 패널·모바일 서랍·메뉴 검색·캐러셀의 설정과 조합 방식은 [메인 레이아웃과 캐러셀](MAIN_LAYOUT.md)을 참고합니다.

## 추가 CSS

고급 스타일에서 기존 CSS 선언 문자열과 AI가 만든 `style.css`의 개별 속성을 편집할 수 있습니다. 편집기에 전용 입력이 없는 방향별 테두리·변형·필터·calc 크기도 저장합니다. CSS는 요소 래퍼의 기본 스타일 위에 적용하며 `style.css`가 기존 `props.customCss`보다 우선합니다. 모바일/태블릿은 지정한 CSS 속성만 덮어쓰며 빈 값으로 해당 선언을 해제합니다. 캔버스·미리보기·HTML/Storybook 내보내기가 같은 렌더러를 사용합니다.

## 모바일 기본 배치

모바일 전용 설정이 없으면 그리드는 기본 1열로 표시하고, 너비가 자동인 컨테이너·카드·그리드는 사용 가능한 가로 공간을 채웁니다. 이미지·하위 컨테이너·카드·그리드·표·차트를 포함하는 가로 배치는 세로로 전환하고 정렬을 stretch로 바꿉니다. 버튼 등 작은 요소만 모인 행은 가로 배치를 유지하며 줄바꿈합니다. PC에서 상속된 최소 너비는 모바일에서 해제하고 긴 텍스트·연락처·버튼 문구는 영역 안에서 줄바꿈합니다. 모바일 세로 배치의 grow 요소는 높이를 0 기준으로 압축하지 않습니다.

기존 문서를 수정하거나 재생성할 필요 없이 표시할 때 적용합니다. 모바일에 직접 지정한 열 수·방향·너비·정렬·줄바꿈은 우선하며 데스크톱/태블릿 데이터는 유지합니다. 가로 스크롤 영역의 방향·열 수는 자동 전환하지 않습니다. 고정/비율 너비와 추가 CSS는 작성 의도를 보존하므로 의도적으로 큰 모바일 최소 너비·변형·nowrap 등을 지정하면 별도 조정이 필요할 수 있습니다. 캔버스 기기 선택, 미리보기, HTML/Storybook 내보내기는 같은 기본 배치를 사용합니다.

## 날짜와 시간

- 입력 종류: 날짜, 시간, 날짜 + 시간. 날짜 범위도 같은 달력을 사용합니다.
- 날짜·날짜 범위는 기본적으로 날짜만 표시합니다. 요소 속성의 **시간 사용 → 사용 / 사용 안 함**으로 시간 선택을 설정합니다. 날짜 + 시간은 기본 사용, 시간 전용 입력은 시·분만 선택합니다.
- 달력 안에는 시간 사용 체크박스, 초/밀리초 선택, 선택 날짜·시간 요약 문구를 두지 않습니다.
- 적용한 후 입력박스에 연월일 또는 연월일과 시·분을 표시합니다. 시간 전용은 시·분만 표시합니다.
- 실제 폼 값은 표시 문구와 분리합니다. 숨겨진 input의 이름은 단일 선택의 경우 요소 ID, 범위의 경우 요소 ID에 `-start`, `-end`를 붙입니다.
- 날짜만 선택해도 실제 값은 `YYYY-MM-DDT00:00:00.000`입니다. 날짜 범위의 종료 값은 `YYYY-MM-DDT23:59:59.999`입니다.
- 시간 사용 시 59분은 `:59.999`, 나머지 분은 `:00.000`을 자동으로 붙입니다. 예: 화면 `12:59` → 값 `12:59:59.999`, 화면 `12:30` → 값 `12:30:00.000`. 범위 시작·종료 모두 같은 규칙입니다.
- 값은 시간대 접미사가 없는 로컬 날짜·시간 문자열입니다. 서버 조회/UTC 변환은 향후 API Binding의 책임입니다.
- 오늘 버튼은 실제 오늘로 월과 선택 날짜를 이동합니다. 범위는 양쪽 날짜를 오늘로 설정합니다. 적용 전 변경은 취소/Escape로 버립니다.
- 미리보기에서 선택한 날짜·입력 값은 화면을 사용하는 동안 유지됩니다. 프로젝트 저장 대상은 요소 설정이며, 미리보기에서 입력한 데이터 자체를 DB에 저장하는 기능은 아닙니다.

## 배치와 데이터

- 모바일·태블릿 스타일은 기본 style에 해당 기기의 일부 값만 덮어씁니다. 모바일 숨김을 바꿔도 기존 간격·방향·너비 설정을 지우지 않습니다.
- 라디오 그룹의 라벨 위치와 옵션 배치/정렬은 별도 설정입니다.
- 테이블 행 수는 헤더를 제외한 데이터 행 수(1–200), 열 수는 1–24입니다. 설정이 없으면 기존 항목에서 계산합니다.
- 행/열을 줄일 때 항목 원문을 지우지 않습니다. 다시 늘리면 기존 내용이 돌아오며 부족한 셀은 빈칸입니다. 페이지당 항목 수는 1–100입니다.
- 페이지 탐색은 좌우 화살표에 고정 공간을 할당합니다. 좁은 컨트롤은 숫자 목록 대신 현재/전체 페이지를 표시합니다. 판단 기준은 브라우저 전체 너비가 아니라 컨트롤 영역 너비입니다.
- 버튼의 너비 기본값과 Inspector의 `내용에 맞춤(auto)`은 버튼 글자와 아이콘에 맞는 intrinsic width로 표시됩니다. 고정 너비를 선택했을 때만 해당 너비를 사용합니다.
- 일반 입력칸·날짜·날짜 범위·단일 선택의 실제 입력 영역은 기본 글자 크기 16px에서 높이 44px, 테두리 1px, 내부 여백 10px/12px를 공유합니다. 라벨과 설명은 높이에서 제외하며 큰 글자에서는 같은 규칙으로 함께 커집니다. 날짜 범위는 긴 값을 한 줄 말줄임으로 표시하고 전체 값은 title/달력에서 확인합니다.
- 가로 컨테이너의 **폼·버튼 정렬 → 입력칸에 맞춤**이 기본입니다. 직접 자식인 입력·날짜·날짜 범위·단일 선택과 버튼을 실제 입력 영역의 세로 중앙에 맞춥니다. 기본 44px 입력 옆 38px 버튼에는 위아래 3px 여유가 생깁니다. 라벨 위치·줄 높이·설명·글자 크기·캔버스 배율이 달라도 측정하며 줄바꿈은 행별로 처리합니다. ‘일반 배치’를 선택하면 기존 위/가운데/아래/채움 정렬을 따릅니다.
- 자동 위치는 DOM의 전용 CSS 변수에만 적용하고 페이지 여백 값으로 저장하지 않습니다. 모바일 세로 배치·그리드에서는 자동 위치를 제거합니다. 자식의 명시적 정렬·위/아래 여백(0 포함)·커스텀 CSS는 보존합니다. 이전에 넣은 35px 등의 여백을 없애려면 **바깥 여백 → 방향 옆 초기화 아이콘**으로 해제하세요. 캔버스·미리보기·HTML ZIP은 같은 렌더러를 사용합니다.
- 스켈레톤은 텍스트 줄/원형과 텍스트/카드 세 종류입니다.

## 속성 패널과 표 편집 (2026-09-16)

- 일반 컨테이너·카드에는 가로/세로 방향, 축에 맞춘 정렬·배분·줄바꿈을 표시합니다. **그리드 열/행 수는 그리드 요소에서만** 표시합니다.
- 기본 가로 배치의 하단 정렬을 모바일 세로 배치로 전환한 기존 화면은, 모바일 정렬을 별도로 지정하지 않았을 때 `stretch`로 보정합니다. 명시적인 모바일 정렬은 유지합니다.
- 버튼/요소 아이콘은 검색 가능한 실제 아이콘 목록에서 선택합니다. 라벨 위치, 내용 정렬, 버튼 모양은 그림 버튼으로 선택하고 선택 상태·키보드 포커스를 제공합니다. 버튼 아이콘 앞/뒤 위치와 간격도 설정할 수 있습니다.
- 부모 방향에 맞춰 요소 자체의 가로/세로 위치를 선택합니다. 부모가 가로이면 남은 공간을 앞에 두어 오른쪽으로 밀 수 있고, 세로이면 아래로 밀 수 있습니다. 그리드 자식은 셀 안 가로·세로 위치를 별도로 설정합니다.
- 너비/높이는 내용·채움·고정 px·비율로 구분합니다. 안쪽/바깥 여백은 방향별 도식, 모서리는 미리보기와 모서리별 숫자 설정을 제공합니다. 테두리·그림자·글자 굵기·줄 높이·투명도와 이미지 맞춤도 저장됩니다.
- 일반 입력칸에 설명/오류 문구, 앞뒤 단위, 지우기 버튼을 설정합니다. 날짜·시간 입력은 전용 달력 설정을 사용합니다. 미리보기의 입력값은 서버에 저장되지 않습니다.
- 표는 **내용 → 표 편집**에서 열, 행·모양, 표시·동작을 나눠 설정합니다. 열 제목/종류/순서/복제/삭제, 기기별 표시, 너비·정렬·줄바꿈·고정을 지원합니다. 종류는 텍스트·숫자·날짜·링크·버튼·아이콘·체크박스·상태 배지·이미지입니다.
- 셀 데이터 대화상자에서 직접 입력하거나 엑셀의 탭/줄바꿈 영역을 붙여넣습니다. 최대 200행·24열, 새 붙여넣기는 셀당 2,000자입니다. 기존 항목의 긴 내용은 변환 시 5,000자까지 보존합니다. 행 표시를 끄면 삭제하지 않고 숨깁니다.
- 행 교차 색상, 조건별 행/배지 색상, 행 간격, 구분선, 헤더 고정, 마우스 강조를 지원합니다. 첫 번째 보조 열은 없음·번호·체크박스·번호+체크 중 선택합니다. 원래 데이터 열은 별도로 숨길 수 있습니다.
- 표 미리보기/HTML ZIP에서 검색·열 필터·헤더 정렬·페이지 탐색·선택을 실행합니다. 전체 선택 범위는 현재 페이지 또는 필터 결과 전체입니다. 셀 체크박스와 행 선택은 독립적이며 서버 저장이 아닙니다. 버튼 셀은 안전한 주소이면 이동하고, 주소가 아니면 선택 표시만 바뀝니다. 외부 API 실행은 아직 연결하지 않았습니다.
- 모바일은 가로 스크롤 또는 행별 카드로 표시할 수 있습니다. 숨긴 열은 두 방식 모두 제외됩니다. 로딩/오류 설정은 디자인 미리보기용입니다. 무한 목록은 현재 저장된 행을 순차 표시하며 외부 API를 호출하지 않습니다.
- 기존 `items`, `rowCount`, `columnCount`는 그대로 읽습니다. 고급 표 설정을 처음 바꿀 때 `props.table` 구조를 저장하며 이후 이 값이 우선합니다. 기존 원문을 보존하고, 기존에 잘린 행/열은 숨김 상태로 변환합니다. 변경은 기존 실행 취소·버전 복원에 포함됩니다.

## HTML ZIP 동작

- `index.html`, `styles.css`, `runtime.js`, `spec.json`, `README.txt`와 이미지 assets를 함께 내보냅니다. 압축을 풀고 index.html을 열 수 있습니다.
- 실제 NodeRenderer와 요소 컴포넌트를 번들링하므로 달력·탭·라디오·페이지 이동·커스텀 CSS·반응형 동작을 공유합니다.
- 모바일 <768px, 태블릿 768–1023px, 데스크톱 ≥1024px입니다.
- 같은 사이트의 이미지 경로는 ZIP에 포함합니다. 외부 첨부파일은 기존 파일 서비스의 공개 주소를 참조하며 인터넷과 유효한 파일이 필요합니다.
- 인증 토큰이나 세션은 내보내지 않습니다. 로그인·업로드·DB 저장·API Binding은 별도 서버 연결이 필요합니다.
- 이번 변경은 HTML ZIP에 적용됩니다. 기존 Storybook ZIP 생성 기능의 독립 실행 완성도는 별도 후속 점검 대상입니다.

## 모달·다이얼로그·Non-modal

세 요소 모두 내부에 다른 요소를 넣을 수 있습니다. 메인 컨테이너에서는 현재 화면 중앙, 특정 컨테이너에서는 화면과 해당 컨테이너가 겹치는 영역의 중앙에 표시합니다. 페이지 전체 높이의 가운데를 사용하지 않습니다. 스크롤·화면 크기·캔버스 확대에 따라 표시 영역을 갱신하며 큰 내용은 창 내부에서 스크롤합니다.

- 모달: 배경 조작 차단, 위치 이동 불가.
- 다이얼로그: 배경 입력·조작 가능, 제목 부분을 끌어 이동 가능. 기본 확인·취소 버튼을 끌 수 있습니다.
- Non-modal: 모달 형태에 배경 조작·이동을 허용합니다.

이동은 미리보기의 임시 상태이며 다시 열면 중앙으로 복귀합니다. 편집 중에는 닫힌 창도 보여 내부 요소를 편집할 수 있습니다. 버튼·아이콘의 클릭 동작에서 창 열기/닫기/전환과 대상 창을 선택합니다. 대상 생략은 그 요소가 들어 있는 창입니다. 요소 그룹 복제 시 내부 대상 ID도 함께 바뀝니다. 창 제목·기본 버튼·처음부터 열기와 모달 배경 클릭 닫기를 속성에서 설정합니다. X 버튼은 투명하며 키보드 포커스 표시를 유지합니다.

일반 화면 미리보기와 HTML ZIP은 공통 NodeRenderer를 사용합니다. 작은 비활성 템플릿 썸네일에서는 창이 외부로 떠오르거나 포커스를 가져가지 않습니다.
