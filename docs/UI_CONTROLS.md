# 편집기 컨트롤 동작

2026-09-16 사용자 정정 사항을 적용한 기준입니다.

## 날짜와 시간

- 입력 종류: 날짜, 시간, 날짜 + 시간. 날짜 범위도 같은 달력을 사용합니다.
- 날짜·날짜 범위는 기본적으로 날짜만 표시합니다. 요소 속성의 **시간 사용 → 사용 / 사용 안 함**으로 시간 선택을 설정합니다. 날짜 + 시간은 기본 사용, 시간 전용 입력은 시·분만 선택합니다.
- 달력 안에는 시간 사용 체크박스, 초/밀리초 선택, 선택 날짜·시간 요약 문구를 두지 않습니다.
- 적용한 후 입력박스에 연월일 또는 연월일과 시·분을 표시합니다. 시간 전용은 시·분만 표시합니다.
- 실제 폼 값은 표시 문구와 분리합니다. 숨겨진 input의 이름은 단일 선택의 경우 요소 ID, 범위의 경우 요소 ID에 `-start`, `-end`를 붙입니다.
- 날짜만 선택해도 실제 값은 `YYYY-MM-DDT00:00:00.000`입니다. 날짜 범위의 종료 값은 `YYYY-MM-DDT23:59:59.999`입니다.
- 시간 사용 시 59분은 `:59.999`, 나머지 분은 `:00.000`을 자동으로 붙입니다. 예: 화면 `12:59` → 값 `12:59:59.999`, 화면 `12:30` → 값 `12:30:00.000`. 범위 시작·종료 모두 같은 규칙입니다.
- 값은 시간대 접미사가 없는 로컬 날짜·시간 문자열입니다. 서버 조회/UTC 변환은 향후 API Binding의 책임입니다.
- 오늘 버튼은 실제 오늘로 월과 선택 날짜를 이동합니다. 범위는 양쪽 날짜를 오늘로 설정합니다. 적용 전 변경은 취소/Escape로 버립니다.
- 미리보기에서 선택한 날짜·입력 값은 화면을 사용하는 동안 유지됩니다. 프로젝트 저장 대상은 요소 설정이며, 미리보기에서 입력한 데이터 자체를 DB에 저장하는 기능은 아닙니다.

## 배치와 데이터

- 모바일·태블릿 스타일은 기본 style에 해당 기기의 일부 값만 덮어씁니다. 모바일 숨김을 바꿔도 기존 간격·방향·너비 설정을 지우지 않습니다.
- 라디오 그룹의 라벨 위치와 옵션 배치/정렬은 별도 설정입니다.
- 테이블 행 수는 헤더를 제외한 데이터 행 수(1–200), 열 수는 1–24입니다. 설정이 없으면 기존 항목에서 계산합니다.
- 행/열을 줄일 때 항목 원문을 지우지 않습니다. 다시 늘리면 기존 내용이 돌아오며 부족한 셀은 빈칸입니다. 페이지당 항목 수는 1–100입니다.
- 페이지 탐색은 좌우 화살표에 고정 공간을 할당합니다. 좁은 컨트롤은 숫자 목록 대신 현재/전체 페이지를 표시합니다. 판단 기준은 브라우저 전체 너비가 아니라 컨트롤 영역 너비입니다.
- 버튼의 너비 기본값과 Inspector의 `내용에 맞춤(auto)`은 버튼 글자와 아이콘에 맞는 intrinsic width로 표시됩니다. 고정 너비를 선택했을 때만 해당 너비를 사용합니다.
- 스켈레톤은 텍스트 줄/원형과 텍스트/카드 세 종류입니다.

## HTML ZIP

- `index.html`, `styles.css`, `runtime.js`, `spec.json`, `README.txt`와 이미지 assets를 함께 내보냅니다. 압축을 풀고 index.html을 열 수 있습니다.
- 실제 NodeRenderer와 요소 컴포넌트를 번들링하므로 달력·탭·라디오·페이지 이동·커스텀 CSS·반응형 동작을 공유합니다.
- 모바일 <768px, 태블릿 768–1023px, 데스크톱 ≥1024px입니다.
- 같은 사이트의 이미지 경로는 ZIP에 포함합니다. 외부 첨부파일은 기존 파일 서비스의 공개 주소를 참조하며 인터넷과 유효한 파일이 필요합니다.
- 인증 토큰이나 세션은 내보내지 않습니다. 로그인·업로드·DB 저장·API Binding은 별도 서버 연결이 필요합니다.
- 이번 변경은 HTML ZIP에 적용됩니다. 기존 Storybook ZIP 생성 기능의 독립 실행 완성도는 별도 후속 점검 대상입니다.
